Browser Context Check

この拡張が送信するもの

Agent Mode を有効にすると、この拡張はあなたが見ているタブの情報を外部サーバーへ送信します。 有効にするまで、送信は一切行われません。

送信先
—
送信する項目
ブラウザ種別・プロファイル名（あなたが付けた名前）・ウィンドウID・タブID・URL・フォーカス状態。タイトルは別スイッチ
送信するタイミング
タブの切替・更新・ウィンドウのフォーカス変化時、および1分ごと
保存期間
インストールごとに最新1件のみ。数分で失効します
停止方法
このページで Agent Mode をオフにするか、下の「解除」を押します

URL のクエリやフラグメント、ページタイトルには機密情報が含まれ得ます。既定ではクエリとフラグメントを 削除して送信します。

ペアリング

CLI 側で発行した一度きりのコードを入力してください。
